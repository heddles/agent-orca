# agent-orca documentation

agent-orca is a Kubernetes-native platform for deploying, managing and running
AI agents. You declare agents, route them to a model, give them tools, and run
them as one-off jobs or long-running services, with checkpoints, cost tracking,
guardrails and retrieval built in.

To install it, follow the [installation guide](installation.md).
