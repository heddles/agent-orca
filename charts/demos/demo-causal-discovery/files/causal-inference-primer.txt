# Causal Inference Primer

## What is Causal Inference?

Causal inference is the process of using statistical methods to draw causal conclusions from data. Unlike correlation, which only tells us whether variables move together, causation tells us whether one variable directly influences another.

## The Causal Diagram (DAG)

A Directed Acyclic Graph (DAG) represents causal relationships:
- Nodes represent variables
- Directed edges represent causal relationships (→ means X causes Y)
- No cycles allowed (you can't have A→B→A)

## Fundamental Concepts

### Confounding
A confounder is a variable that affects both the treatment and outcome, creating a spurious association. For example:
- Ice cream sales and drowning deaths are correlated
- The confounder is temperature: hot weather increases both ice cream sales and swimming (leading to drownings)

### Collider Bias
A collider is a variable that is caused by two other variables. Conditioning on a collider opens a non-causal path between its causes.

### Instrumental Variables
An instrumental variable Z affects the treatment X but has no direct effect on outcome Y, only through X. Useful for addressing unmeasured confounding.

## Methods

### 1. Randomized Controlled Trials (RCTs)
Gold standard for causal inference. Randomization breaks all confounding paths.

### 2. Regression Adjustment
Control for measured confounders in observational data using regression.

### 3. Propensity Score Matching
Match treated and control units on their probability of treatment given covariates.

### 4. Difference-in-Differences
Compare changes over time between treated and control groups.

### 5. Synthetic Control
Create a weighted combination of control units to serve as a counterfactual.
